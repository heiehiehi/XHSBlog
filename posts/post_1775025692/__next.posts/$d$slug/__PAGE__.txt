f:T1512,<h3>分子动力学模拟流程记录（我命令基本上都是写在word，此处整理记录在博客上）</h3>
<p>针对蛋白质和配体体系（以STAT3蛋白和小分子为例）</p>
<h3>1.获取分子对接后构象及处理</h3>
<p>受体蛋白获取后保存为PDB。此处命名为protein.pdb</p>
<p>配体通过Sobtop处理（需要mol2格式）</p>
<p>将配体文件mol.mol2拖动Sobtop软件中进行处理，回车</p>
<p>选择1，生成top文件</p>
<p>选择3，尽可能使用GAFF力场<br>
选择0，下一步<br>
选择4，如果可能，预先构建成键参数，任意猜测缺少的选项<br>
回车，生成的top文件生成在sobtop软件根目录下<br>
回车，生成的itp位置限制文件在sobtop软件根目录下<br>
选择2，生成gro文件<br>
回车，生成的gro文件在sobtop软件根目录下<br>
回车，退出sobtop软件<br>
随后获取</p>
<p>mol.gro<br>
mol.itp</p>
<p>mol.top文件到根目录下</p>
<h3>2.获取蛋白质构象，生成.top文件</h3>
<pre><code>gmx pdb2gmx -f protein.pdb -o protein.gro -p topol.top -ignh
</code></pre>
<p>我所用的力场是amber14sb_parmbsc1.ff</p>
<p>随后生成topol.top等文件</p>
<h3>3.合并生成.gro文件</h3>
<p>将mol.gro与protein.gro文件合并，得到complex.gro文件。</p>
<p>合并如下代码图所示</p>

<h3>4.对小分子生成限制势文件</h3>
<pre><code>gmx genrestr -f mol.gro -o posre_mol.itp
</code></pre>
<p>随后在mol.itp文件末尾添加</p>
<pre><code>#ifdef POSRES
#include "posre_mol.itp"
#endif
</code></pre>
<h3>5.把小分子文件引入topol.top</h3>
<ul>
<li><strong>引入配体 itp</strong>：由于 <code>mol.itp</code> 定义了新的 <code>[atomtypes]</code>，必须将其放在力场引入之后、蛋白质 itp 引入之前。</li>
<li><strong>增加配体分子数量</strong>：在文件末尾的 <code>[molecules]</code> 中添加配体。</li>
</ul>
<pre><code>; Include forcefield parameters
#include "amber99sb-ildn.ff/forcefield.itp"

; Include chain topologies (注意顺序：配体在蛋白之前)
#include "mol.itp"
#include "topol_Protein_chain_A.itp"
#include "topol_Ion_chain_A2.itp"

; Include water topology
#include "amber99sb-ildn.ff/tip3p.itp"

; ... 中间水模型限制势及离子引入代码略 ...

[ system ]
; Name
Protein-Ligand Complex in water

[ molecules ]
; Compound        #mols
Protein_chain_A   1
Ion_chain_A2      1
mol               1   ; 注意此处需要有空格，并确保有换行符
</code></pre>
<h3>6.设定盒子、溶剂化与添加离子</h3>
<pre><code>生成立方体盒子，边缘距离分子至少 1.0 nm
gmx editconf -f complex.gro -o complex_box.gro -d 1.0 -bt cubic
</code></pre>
<p>添加水分子</p>
<pre><code>gmx solvate -cp complex_box.gro -o complex_SOL.gro -p topol.top
</code></pre>
<h3>7.添加离子（中和体系）</h3>
<p>生成临时 <code>.tpr</code> 文件用于加离子：</p>
<pre><code>gmx grompp -f em.mdp -c complex_SOL.gro -p topol.top -o em.tpr -maxwarn 1
</code></pre>
<p>替换水分子为离子以中和体系：</p>
<pre><code>gmx genion -s em.tpr -p topol.top -o system.gro -neutral
</code></pre>
<ul>
<li>提示选择组时，选择 <code>SOL</code>（溶剂组）。</li>
</ul>
<h3>8.能量极小化 (EM)</h3>
<p>消除体系内的空间位阻和不合理的接触：</p>
<pre><code>gmx grompp -f em.mdp -c system.gro -p topol.top -o em.tpr -maxwarn 1
gmx mdrun -v -deffnm em
</code></pre>
<h3>9.分组</h3>
<p>为了后续成品动力学控温和去平动/转动，需要将“蛋白-离子-配体”合并为一个组：</p>
<pre><code>gmx make_ndx -f pr.gro
</code></pre>
<p>在交互界面中依次输入：</p>
<ul>
<li><code>x 1 | x 2 | x 3</code> （假设 1,2,3 分别是蛋白、配体、离子，具体组号请根据屏幕提示确认）</li>
<li><code>name R protein_lig</code> （给新组命名为蛋白_配体，假设新组号为 R）</li>
<li><code>! R</code> （把其他所有环境/溶剂定义为另一个组）</li>
<li><code>name R+1 envir</code> （命名为环境）</li>
<li><code>q</code> （保存并退出，生成 <code>index.ndx</code>）</li>
</ul>

</code></pre>
